# MediQuick – Online Pharmacy & Delivery System

## Purpose
MediQuick lets customers search medicines, upload prescriptions, place
orders and track delivery, so they do not need to visit a pharmacy.

## Group Members
- Muhammad Saood (solo – all roles)

## Technologies
- Python 3 + Flask (REST API)
- pytest (testing)
- Jira (Scrum planning) and GitHub (version control)

## Run
pip install -r requirements.txt
python app.py
